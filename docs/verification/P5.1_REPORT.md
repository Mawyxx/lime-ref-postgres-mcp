## Implementation walkthrough

### Facade (`bootstrap/observability/`)

1. `configure_observability(level, format, stream_name|stream, metrics_enabled)` — idempotent; composition-only.
2. `log(component, event, **fields)` — schema `lime.mcp.process_log.v1`; redact; never raises into UC.
3. `metrics.inc` / `observe_ms` / `snapshot` — no-op when `LIME_MCP_METRICS=0`.
4. `bind_context` / `clear_context` — contextvars; stream resolves `sys.stderr`/`stdout` at emit time (pytest-safe).

### Correlation shell (`server.on_call_tool`)

1. `request_id = runtime.ids.new_request_id()`.
2. Parse `traceparent` best-effort → bind.
3. `tools.call.start` → handler(`request_id`) → `tools.call.done` + `mcp_tools_call_*`.
4. `finally: clear_context()`.
5. Same `request_id` on `InvokeAgentToolCommand` → `RequestContext` → `AgentActionEvent.meta.request_id` when event exists.

### Establish / Authorize / Emit

- **Establish:** `preauth.fail` + `mcp_preauth_fail_total` on Err; `context.ok` + `bind(agent_id)` on Ok. No emit on pre-auth.
- **Authorize:** exit-only `authorize.allow|deny` + deny counter (thin `_authorize` wrapper).
- **Emit:** after bus.emit → `emit` + `mcp_emit_total`.

### Adapters

- **Verifier:** `verify.ok|fail`, `jwks.warmup`.
- **Policy:** `policy.load|reload|soft_keep`.
- **DB:** `_with_txn` → `db.op` + `mcp_db_op_*`; lazy `pool.open`.
- **Bus:** stdlib logger replaced → `sink.error` + `mcp_sink_error_total` (still swallow).
- **CLI:** product `print` → `serve.start|stop`, `config.error`, `composition.ok`.

**Return contract:** Result / AgentReply / CallToolResult unchanged by logging failures.

## Naming & readability

- Event names match TDD matrix (`preauth.fail`, `db.op`, `tools.call.done`) — searchable in JSONL.
- Facade verbs (`log`, `metrics`, `bind_context`) avoid a Logger port (ADR-003 / A06 I/O ports stay real).
- `stream_name` vs captured `stream` keeps tests and serve both correct.
